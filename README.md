# Розыгрыш по посту ВКонтакте

Сайт для розыгрышей «Фабрики суши»: вставляете ссылку на пост, сайт проверяет условия, честно выбирает победителей и собирает картинку с их аватарками и именами.

Сайт: https://ubicasmerti228.github.io/testfabrika/

## Что умеет

- Проверяет условия: лайк, репост, подписка на сообщество, активная страница (не удалена и не заблокирована).
- Дополнительно: исключить страницы без аватарки, закрытые профили, список людей (админы, прошлые победители), проверить подписку на другое сообщество.
- Показывает, сколько людей отсеялось на каждом шаге.
- Выбирает победителей через `crypto.getRandomValues` (равномерно, без перекоса), с анимацией барабана.
- Перевыбор любого места.
- Картинка 1254×1254 в стиле шаблона: скачать или поделиться с телефона.
- Список победителей одной кнопкой и протокол розыгрыша (.txt) со всеми участниками и контрольной суммой списка.
- Тестовый режим без ключа ВК.

## Как пользоваться

1. Создайте приложение ВКонтакте (dev.vk.com или кабинет VK ID для бизнеса) и скопируйте его «Сервисный ключ доступа».
2. На сайте нажмите «Ключ ВК», вставьте ключ и сохраните. Ключ хранится только в вашем браузере.
3. Вставьте ссылку на пост, отметьте условия, нажмите «Проверить участников», затем «Разыграть».

Ссылку можно передать в адресе: `?post=https://vk.com/wall-215596190_1837`.

## Ограничения

- ВКонтакте не показывает репосты в закрытые профили и в личные сообщения, такие люди не попадут в розыгрыш.
- Запросы идут прямо из браузера (JSONP), не чаще 3 в секунду, поэтому на больших постах проверка занимает время.
- Если ВК не отдаст фото для сохранения в файл, сайт попробует загрузить его через images.weserv.nl. Если и это не получится, картинку можно сохранить скриншотом.

## Файлы

- `index.html`, `style.css`, `app.js` — сайт, без сборки и зависимостей.
- `assets/template.webp` — шаблон картинки с прозрачными окнами под аватарки.
- Координаты окон и подписей — в начале `app.js` (объект `POSTER`). Чтобы сменить шаблон, замените картинку и поправьте координаты.
