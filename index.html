Ключ доступа ВКонтакте

На сайте уже есть встроенный ключ, и он работает без настройки. Свой сервисный ключ нужен, только если встроенный перестанет работать. Свой ключ хранится в этом браузере и отправляется только во ВКонтакте.

Где взять ключ
  1. Откройте раздел для разработчиков ВК (dev.vk.com) или кабинет VK ID для бизнеса и создайте приложение.
  2. Подтвердите действие по телефону, если ВК попросит.
  3. В настройках приложения найдите поле «Сервисный ключ доступа» и скопируйте его сюда.
